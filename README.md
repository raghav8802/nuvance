# Nuvance and Co — Website

Static website for Nuvance and Co (Accounting • Taxation • Advisory).

Open `index.html` in a browser, or serve the folder with any static host (GitHub Pages, Netlify, Vercel).
For local preview: `python3 -m http.server` then visit http://localhost:8000.

- `css/style.css` – styles, light/dark theme
- `js/app.js` – content, interactions, tax/GST calculators, compliance tracker
- `js/scene.js` – Three.js 3D hero logo and interactive globe (loaded from jsDelivr CDN)
